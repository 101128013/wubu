# 🚀 Quick Start Guide - Easy OSINT

## For Complete Beginners

### What is OSINT?
OSINT = Finding public information about people online. Like looking them up in a phone book, but for the internet!

### Why Use Easy OSINT?
- ✓ Super simple (5 easy steps)
- ✓ No complicated setup
- ✓ Works on any computer
- ✓ Perfect for learning

---

## 🎯 Get Started in 30 Seconds

### Step 1: Open the File
1. Find file: **osint_ui.html**
2. Double-click to open in browser
3. See the friendly purple interface

### Step 2: Click "Let's Start!"
See the big green button?  
Click it!

### Step 3: Choose What to Search
- 📧 Email
- 👤 Username
- 🌐 Website
- ☎️ Phone

### Step 4: Type What You're Looking For
Example: john@example.com

### Step 5: See Results!
The app finds public profiles and shows what it found.

**Problem:** File won't open

**Solution:** Use Ctrl+Plus to zoom in, Ctrl+Minus to zoom out

**Problem:** Nothing happens when I click
**Solution:** Make sure you filled in all the fields
